# 🛡️ IMT Lazarus Blocker & Proxy (.pac)

Una solución mediante **servidor proxy local y/o archivo PAC (Proxy Auto-Configuration)** diseñada para interceptar, filtrar y bloquear el tráfico y los dominios de control de **IMT Lazarus**.

Puedes usar directamente el enlace del script PAC que ya está activo, crear tu propio **GitHub Gist**, aloja la solución en tu propio repositorio de **GitHub** o ejecutar el proxy localmente en `localhost` con el código incluido en este repositorio.
